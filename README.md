# Python for SRE & Automation 🛠️

Welcome to my repository dedicated to learning and implementing Python for Site Reliability Engineering. This repo tracks my 30-day journey of mastering automation to reduce toil and improve system reliability.

## 📌 Roadmap
- **Phase 1:** Core Scripting (Lists, Dicts, Loops, Functions)
- **Phase 2:** System Automation (`os`, `sys`, `subprocess`)
- **Phase 3:** API & Cloud Integrations (`requests`, `boto3`)
- **Phase 4:** Log Parsing & Monitoring Automation

## 📂 Project Structure

| File Name | Description | Topic |
| :--- | :--- | :--- |
| `disk_monitor.py` | Checks disk usage and sends alerts. | System Monitoring |
| `log_analyzer.py` | Parses Nginx/System logs for Error patterns. | Log Management |
| `mongo_health_check.py`| Validates MongoDB connection and status. | DB Reliability |
| `api_status_checker.py`| Pings service endpoints and logs uptime. | Web Reliability |
